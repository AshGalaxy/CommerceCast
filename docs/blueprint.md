# **App Name**: Foresight Analytics

## Core Features:

- Interactive Sales Dashboard: Visualizations of historical data (sales, revenue, units) with filters.
- Trend Identification: Automatic detection and display of seasonal and long-term trends.
- Comparative Analysis: Ability to compare metrics across products, categories, or time periods.
- AI-Powered Demand Forecasting: Uses historical data and ML models for future sales prediction. An AI tool evaluates the forecasts and generates recommendations.
- AI Dynamic Ensemble Forecasting: Automatically selects and blends the best models (Prophet, XGBoost, etc.) for highest accuracy. An AI tool evaluates the forecasts and generates recommendations.
- Uncertainty Intervals: Visual representation of forecast confidence levels.
- Smart Promotion Planner: Suggests optimal times/products for promotions based on forecast dips. An AI tool evaluates the promotions and generates recommendations.
- What-If Scenario Sandbox: Simulates the impact of decisions (discounts, marketing spend) on future sales.
- Automated Inventory & Reorder Alerts: Calculates reorder points and triggers alerts to prevent stock-outs.
- Anomaly Detection & Opportunity Alerts: Proactively notifies users of significant deviations from the forecast.
- Multiple Data Input Options: Manual Upload, Google Sheets Sync.
- AI Business Analyst & Insight Narrator: LLM-generated plain-language summaries of dashboard data and actionable advice.
- Interactive Funnel Drop-off Visualizer: Visualizes where customers abandon the purchase process.
- Silent Competitor Price Tracker: Automatically monitors competitor prices via web scraping.
- User Authentication: Secure login/registration via Firebase Auth.
- Customizable Report Generation: Ability to create and export specific reports (planned feature).

## Style Guidelines:

- Primary color: Electric Blue (#7DF9FF) to evoke data-driven clarity and confidence.
- Background color: Light gray (#E0E0E0), for a clean, data-focused appearance that prevents eye strain.
- Accent color: Sky Blue (#87CEEB), used for interactive elements, buttons, and highlighting important data points.
- Body and headline font: 'Inter', sans-serif, for clear data presentation
- Use a modern, minimalist icon set for representing data categories and functionalities.
- Employ a grid-based layout to maintain structure and organization.
- Incorporate subtle transitions for data updates.
